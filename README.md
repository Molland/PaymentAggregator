# Кейсы платежного агрегатора. Тестовое задание

## Инструкция:
1. Клонируйте репозиторий.
2. Откройте файл `database.sql` в MS SQL Server Management Studio и выполните его для создания структуры и наполнения БД.
3. Проверьте строку подключения `DefaultConnection` в файле `Web.config` и при необходимости укажите ваш адрес локального сервера MS SQL.
4. Откройте решение в Visual Studio и запустите проект.

[ENG]
# Payment aggregator cases. Test task

## Instructions:
1. Clone the repository.
2. Open the `database.sql` file in MS SQL Server Management Studio and execute it to create the structure and populate the database.
3. Check the `DefaultConnection` connection string in the `Web.config` file and, if necessary, specify your local MS SQL server address.
4. Open the solution in Visual Studio and run the project.
